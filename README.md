## Sistema de Cadastro de Clientes

## Sobre

Esse projeto foi desenvolvido por mim para praticar Java e Programação Orientada a Objetos durante os estudos da faculdade.

A ideia foi criar um sistema simples de cadastro de clientes para colocar em prática os conteúdos que estou aprendendo, como classes, objetos, encapsulamento, getters e setters, métodos, ArrayList e lógica de programação.

Pretendo continuar evoluindo esse projeto conforme for aprendendo novos conteúdos.

## Funcionalidades

* Cadastrar clientes
* Listar clientes
* Buscar cliente pelo CPF
* Alterar dados do cliente
* Excluir cliente
* Menu interativo no console
